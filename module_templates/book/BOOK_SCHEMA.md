# Schema: Book

## Purpose
Manifest grouping related pages from the same shelf into a coherent narrative.

## YAML Frontmatter

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | yes | Auto: `b_XXX` |
| `title` | string | yes | Book title |
| `shelf` | string | yes | Shelf path |
| `pages` | list | yes | Ordered page IDs |
| `description` | string | no | Summary |
| `updated_at` | date | yes | Last rebuild date |
| `owner` | string | yes | Owning agent |

## Rules
1. Auto-generated from shelf pages — never hand-written
2. One book per shelf per time period
3. Regenerated by `rebuild_index.py`
4. Edit source pages, rebuild to update
