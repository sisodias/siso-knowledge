# The Skills Hub system — architecture, registry, and invocation

## What is the Skills Hub?

The SISO Skills Hub is a centralized library of reusable task recipes that agents use to perform specialized work. Skills are versioned, categorized, and tracked for quality.

## Architecture

```
agent_os/skills_hub/
├── registry/
│   ├── skills/           # 29 skills, each with SKILL.md
│   └── skills_registry.json  # Master index
├── scripts/
│   ├── skills            # CLI entry point
│   ├── skills_diagnose.py    # Error analysis + auto-degradation
│   ├── skills_telemetry.py   # Invocation tracking SDK
│   ├── skills_integrator.py  # Install skills to agents
│   ├── skills_researcher.py # Discover new skills
│   ├── skills_strategist.py  # Skill planning
│   ├── skills_health_monitor.py
│   └── skill_tracker_hook.py  # PostToolUse hook for telemetry
└── pipelines/               # Skill chaining YAMLs
```

## Invocation

Agents invoke skills via the Claude Code Skill tool (`/skill-name`) or by running skill scripts directly via Bash.

Skill telemetry is captured via a PostToolUse hook that intercepts Bash commands and extracts skill IDs from paths.

## Skill Structure

Each skill lives at:
```
skills_hub/registry/skills/<skill_id>/SKILL.md
```

With optional:
- `README.md` — full documentation
- `scripts/` — executable scripts
- `examples/` — usage examples
