# Global skills — os-database, subagents, skills-hub-usage

Global skills are available to all agents without dependencies.

## os-database

**ID:** `os-database`
**Category:** global
**Purpose:** Core Agent OS database for telemetry, tasks, and timeline tracking

Core scripts: `init_session.py`, `log_event.py`, `create_task.py`, `update_task.py`, `get_my_tasks.py`, `recent_events.py`, `track_time.py`, `time_report.py`, `estimate_task.py`, `bulk_update.py`, `archive_task.py`, `run_automations.py`, `propagate_unblock.py`, `detect_cycle.py`, `use_template.py`, `create_template.py`, `add_field.py`, `get_fields.py`, `set_field.py`, `create_context.py`, `list_contexts.py`, `use_context.py`, `create_cycle.py`, `list_cycles.py`, `update_cycle.py`, `log_hook.py`

Database: `~/.SystemDB/siso_system.db` (WAL mode, active writes)

**Dependency:** sqlite3 (pre-installed)

## subagents

**ID:** `subagents`
**Category:** global
**Purpose:** Spawn and manage parallel subagents for concurrent task execution

Used via the Agent tool with subagent types: Explore, Plan, general-purpose, context-gatherer, test-runner, web-researcher, scribe-agent, git-workflow, git-researcher, social-researcher, researcher-general, file-creator, context-fetcher, agent-runner, web-researcher, git-researcher

Key behaviors: spawn in parallel, use one task per subagent, resume via agent ID.

## skills-hub-usage

**ID:** `skills-hub-usage`
**Category:** global
**Purpose:** Navigate, discover, install, and use skills from the SISO Skills Hub

CLI: `python3 skills_hub/scripts/skills list`, `skills search <query>`, `skills diagnose <skill>`, `skills recommend <agent>`

Install: `skills install <skill_id> --agent <agent_name>`
