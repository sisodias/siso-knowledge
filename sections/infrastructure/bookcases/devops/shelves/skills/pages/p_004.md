# Communication skills — agent-commander, cli-runner, meta-commander, task-commander

## agent-commander

**ID:** `agent-commander`
**Category:** communication
**Dependencies:** cmux
**Purpose:** Create workspaces, start agents, and communicate with them via CMUX

Commands: create workspace, spawn agent, send message, broadcast, shutdown request, receive responses.

## cli-runner

**ID:** `cli-runner`
**Category:** communication
**Purpose:** Run SISO CLI commands and interact with agents

CLI location: `~/.claude/bin/`

## meta-commander

**ID:** `meta-commander`
**Category:** communication
**Dependencies:** cmux
**Purpose:** Communicate with META agents in the SISO ecosystem

Uses SendMessage tool to DM META agents, broadcast to all, or request shutdown.

## task-commander

**ID:** `task-commander`
**Category:** system
**Dependencies:** cmux, pm-tasks
**Purpose:** Log tasks and communicate with agents using the SISO task database

Combines task database operations with agent messaging. Used by PM_Agent to assign work and track progress.
