# Data skills — websearch, xsearch, multisearch, gitsearch

## websearch

**ID:** `websearch`
**Category:** data
**Purpose:** Search the web using Perplexity Sonar via OpenRouter
**API:** Requires OpenRouter API key

Returns synthesized summaries with source links. Used for real-time research, documentation, and current events.

## xsearch

**ID:** `xsearch`
**Category:** data
**Dependencies:** websearch
**Purpose:** Search X (Twitter) for discussions, opinions, and latest updates

Used for community sentiment, trend tracking, and social research.

## gitsearch

**ID:** `gitsearch`
**Category:** data
**Dependencies:** cli-runner
**System dep:** `gh` (GitHub CLI — `brew install gh`)
**Purpose:** Search GitHub for code, repos, issues, and PRs

Version 2.0.0. Used for finding examples, tracking down bugs, and discovering libraries.

## multisearch

**ID:** `multisearch`
**Category:** data
**Dependencies:** websearch, gitsearch, xsearch
**System dep:** `gh`
**Purpose:** Run web, GitHub, and X searches in parallel for comprehensive research

Spawns all three search agents concurrently and synthesizes results. Best for complex research tasks requiring multiple sources.
