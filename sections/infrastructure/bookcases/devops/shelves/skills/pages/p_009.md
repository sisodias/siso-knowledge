# Testing skills — playwright

## playwright

**ID:** `playwright`
**Category:** testing
**System dep:** `@playwright/cli` (`npm install -g @playwright/cli@latest`)
**Purpose:** Automated browser testing for SISO Internal Lab

Used by QA_Testing_Agent for end-to-end testing of the vibe-kanban codebase.

Capabilities: page navigation, element interaction, screenshot capture, console error detection, flow testing.

Commands: `test:install`, `test:pages`, `test:flow`, `test:screenshot`, `test:console`

CMUX integration for browser automation via `cmux-browser`.
