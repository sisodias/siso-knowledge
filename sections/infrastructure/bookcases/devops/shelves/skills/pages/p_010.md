# Skill telemetry — tracking, diagnosis, and auto-degradation

## How Tracking Works

A PostToolUse hook in each agent's `.claude/settings.json` intercepts every Bash command:

```
python3 skills_hub/scripts/skill_tracker_hook.py
```

The hook reads stdin (Claude Code hook JSON), extracts the skill ID from the command path, and calls `skills_telemetry.track()`.

**Limitation:** Only Bash commands that match skill path patterns are tracked. Skill tool invocations (via `/skill-name`) are NOT tracked — they don't go through Bash.

## Telemetry Storage

Table: `skill_events` in `~/.SystemDB/siso_system.db`

Schema: `event_id, skill_id, agent_id, session_id, timestamp, duration_ms, success, error_type, context_hash, input_size, output_size`

Indexes on `skill_id` and `timestamp`.

## Diagnosis

`skills_diagnose.py` analyzes error rates and auto-degrades skills:

```bash
skills diagnose <skill_id> --days 30
skills diagnose --weekly  # All skills, last 7 days
```

Auto-degradation threshold: **20% error rate**. When exceeded, the skill's status in `skills_registry.json` is set to `degraded`.

## Dashboard

The whitebox server (`agent_os/whitebox/server.ts`) exposes API endpoints for skill telemetry:
- `GET /api/skills/health` — skill health overview
- `GET /api/skills/<skill_id>/stats` — per-skill invocation counts and error rates
