# Devops skills — cmux, cmux-browser, github, vercel

## cmux

**ID:** `cmux`
**Category:** devops
**Purpose:** Terminal multiplexer for Claude Code with socket API for workspace control and browser automation
**Install:** `brew install cmux` or from github.com/shaansisodia/cmux

Core to the SISO agent OS — enables multiple workspaces (panes), persistent sessions, and the socket API for programmatic workspace control.

## cmux-browser

**ID:** `cmux-browser`
**Category:** devops
**Dependencies:** cmux
**Purpose:** Control CMUX browser for automated testing and browser interactions

Enables headless browser automation for UI testing and screenshot capture.

## github

**ID:** `github`
**Category:** devops
**System dep:** git (pre-installed on macOS)
**Purpose:** Complete GitHub workflow — branch, commit, push, merge

Wraps `gh` CLI for repository operations, PR creation, issue management.

## vercel

**ID:** `vercel`
**Category:** devops
**System dep:** `vercel` (`npm install -g vercel`)
**Purpose:** Deploy SISO Internal Lab to Vercel

Used by CI/CD pipeline for automated deployments. Optional `deploy.md` for custom deploy configs.
