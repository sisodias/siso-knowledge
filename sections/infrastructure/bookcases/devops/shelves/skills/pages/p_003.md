# Code skills — agent-builder, agent-setup, analyze_task, implement_story, verify_story

## agent-builder

**ID:** `agent-builder`
**Category:** code
**Purpose:** Create new agents from the SISO v3 agent template

Template: `agent_os/module_templates/agents/live/v3/`

Agent structure: `.a0proj/`, `config/`, `inbox/`, `memory/`, `skills/`, `AGENTS.md`, `SOUL.md`, `CLAUDE.md`, `STYLE.md`, `TOOLS.md`, `USER.md`

Copy command: `cp -r <template> <agent_dir>`

## agent-setup

**ID:** `agent-setup`
**Category:** code
**Purpose:** Create new agent from V4 template with memory system pre-configured

V4 template uses `identity.yaml` at root level, has `inbox/`, `outbox/`, `workspace/`, `SOUL.md`.

## analyze_task

**ID:** `analyze_task`
**Category:** code
**Purpose:** Analyze a task and decompose into user stories

Used by Planner_Agent in the execution pipeline. Takes a task description and breaks it into implementable stories with acceptance criteria.

## implement_story

**ID:** `implement_story`
**Category:** code
**Purpose:** Implement a single user story with tests

Used by Execution_Agent. Follows the story's acceptance criteria and produces working code with test coverage.

## verify_story

**ID:** `verify_story`
**Category:** testing
**Purpose:** Verify a story implementation meets acceptance criteria

Used by Verifier_Agent. Reads the story definition and checks if the implementation satisfies all criteria.
