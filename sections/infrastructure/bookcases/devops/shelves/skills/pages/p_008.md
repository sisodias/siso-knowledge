# Pipeline skills — check_status, create_progress, read_job_ticket, pass_to_next

These skills are used by the SISO execution pipeline for orchestrating multi-agent workflows.

## check_status

**ID:** `check_status`
**Category:** pipeline
**Purpose:** Check the current status of a pipeline run by reading progress files

Reads `progress.md` in the pipeline workspace. Returns: current stage, completed steps, pending steps, any errors.

## create_progress

**ID:** `create_progress`
**Category:** pipeline
**Purpose:** Initialize or update progress.md for a pipeline run

Creates the progress file on pipeline start, then updates it after each stage completes.

## read_job_ticket

**ID:** `read_job_ticket`
**Category:** pipeline
**Purpose:** Read and validate a JobTicket JSON file from inbox

JobTickets are the legacy task format (before siso-tasks.db). This skill reads them, validates schema, and extracts task metadata.

## pass_to_next

**ID:** `pass_to_next`
**Category:** pipeline
**Purpose:** Pass context to the next agent in the pipeline by writing output files

Writes handoff files that the next agent reads on boot. Used for agent-to-agent communication in the execution pipeline.

## Pipeline Flow

```
read_job_ticket → Planner_Agent (analyze_task) → Execution_Agent (implement_story)
→ QA_Agent (playwright) → Verifier_Agent (verify_story) → PR_Agent (github)
```

Each stage uses check_status, create_progress, and pass_to_next.
