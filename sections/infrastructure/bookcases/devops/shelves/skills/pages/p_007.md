# System skills — pm-tasks, task-manager, workspace

## pm-tasks

**ID:** `pm-tasks`
**Category:** system
**System dep:** sqlite3
**Purpose:** Simple PM task manager — create, list, update tasks

Thin wrapper around `siso-tasks.py`. Used for basic task CRUD without the full pipeline overhead.

## task-manager

**ID:** `task-manager`
**Category:** system
**System dep:** sqlite3
**Purpose:** Full task pipeline system with steps, artifacts, and execution logging

More capable than pm-tasks: supports subtasks, artifacts, task relationships, custom fields, cycles, automations, and context management.

**Key difference from pm-tasks:** task-manager handles the full execution lifecycle including logging, dependencies, and automation triggers.

## workspace

Used by agents on boot to understand their environment.
