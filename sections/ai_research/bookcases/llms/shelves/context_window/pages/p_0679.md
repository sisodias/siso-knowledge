# Rectified RoPE - Improved Rotary Position Embeddings

**Repository**: [bojone/rerope](https://github.com/bojone/rerope)

**Stars**: 388 | **Language**: Python | **Updated**: 2026-03-06

**Description**: Rectified Rotary Position Embeddings - addresses RoPE's extrapolation problems when extending context length beyond training distribution.

**Research**: RoPE is widely used in modern LLMs (LLaMA, Mistral, etc.) but suffers from extrapolation issues when inputs exceed training context length. ReRoPE addresses this with a modified position encoding that extrapolates better.

**Why it matters**: Critical for extending context length of existing models via fine-tuning. ReRoPE modification has been adopted in several long-context LLM projects.
