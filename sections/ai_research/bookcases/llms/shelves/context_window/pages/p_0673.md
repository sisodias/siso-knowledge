# SeerAttention - Learned Intrinsic Sparse Attention

**Repository**: [microsoft/SeerAttention](https://github.com/microsoft/SeerAttention)

**Stars**: 198 | **Language**: Python | **Updated**: 2026-03-13

**Description**: SeerAttention learns intrinsic sparse attention patterns for each LLM rather than using fixed sparse patterns. Adapts to the specific attention dynamics of each model.

**Research**: Different LLMs develop different attention patterns during training. Instead of hardcoding sparse patterns, SeerAttention learns which tokens to attend to for each specific model. This adaptive approach can outperform fixed sparse patterns.

**Why it matters**: Moves beyond one-size-fits-all sparse attention toward model-specific learned sparsity. Microsoft's research on adaptive attention.
