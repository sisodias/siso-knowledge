# Unified Sequence Parallel Attention (USP)

**Repository**: [feifeibear/long-context-attention](https://github.com/feifeibear/long-context-attention)

**Stars**: 652 | **Language**: Python | **Updated**: 2026-03-20

**Description**: USP (Unified Sequence Parallel) - also called Hybrid or 2D Sequence Parallel Attention for Long Context Transformers Model Training and Inference. Extends ring attention to 2D topologies for better scalability.

**Research**: Goes beyond linear ring attention by organizing devices in 2D grids, enabling better load balancing for certain attention patterns. Combines with tensor parallelism for distributed training at scale. Active development with recent updates.

**Why it matters**: 2D parallelism is the next step for scaling to million-token+ context lengths. Bridges gap between ring attention and tensor parallelism.
