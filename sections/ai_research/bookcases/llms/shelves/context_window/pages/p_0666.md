# Ring Attention with Flash Attention

**Repository**: [zhuzilin/ring-flash-attention](https://github.com/zhuzilin/ring-flash-attention)

**Stars**: 997 | **Language**: Python | **Updated**: 2026-03-19

**Description**: Ring attention implementation with flash attention. Enables distributed training/inference for extremely long sequences by dividing attention computation across devices in a ring topology.

**Research**: This is the canonical ring attention implementation that combines FlashAttention with context parallelism. Each device computes attention for a segment of the sequence, then passes activations to the next device. Scales linearly with device count for context length. Key reference for implementing long-context training pipelines.

**Why it matters**: Ring attention is foundational for training models with context lengths beyond single-GPU memory. Powers many long-context LLM training setups.
