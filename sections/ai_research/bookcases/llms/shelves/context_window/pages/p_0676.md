# StreamingLLM - Efficient Streaming with Attention Sinks

**Repository**: [EIT-NLP/StreamingLLM](https://github.com/EIT-NLP/StreamingLLM)

**Stars**: 39 | **Language**: Python | **Updated**: 2026-03-20

**Description**: Repository of Streaming LLMs - enables LLMs to generate output from infinitely long text streams without fine-tuning. Uses attention sink mechanism to stabilize performance.

**Research**: Key insight: LLMs have attention "sinks" - special tokens that accumulate attention weight even without being semantically relevant. By keeping these sink tokens in the KV cache, streaming performance stabilizes even with unbounded input length. Practical for chatbots and document summarization pipelines.

**Why it matters**: The attention sink technique is widely used in production streaming systems. Simple to implement, no fine-tuning required.
