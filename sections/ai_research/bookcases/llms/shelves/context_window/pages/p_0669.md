# KVQuant: 10 Million Context Length via KV Cache Quantization

**Repository**: [SqueezeAILab/KVQuant](https://github.com/SqueezeAILab/KVQuant)

**Stars**: 409 | **Language**: Python | **Updated**: 2026-03-20

**Description**: NeurIPS 2024 paper. Quantizes KV cache to enable LLM inference with up to 10 million context length. Uses per-channel quantization and careful kernel design.

**Research**: Key insight: KV cache is the memory bottleneck for long contexts. Quantizing the KV cache (not just weights) dramatically reduces memory footprint. Uses non-uniform quantization and per-token dynamic scaling. Achieves 10M context length on a single A100.

**Why it matters**: Practical solution for extending context length without model changes. The NeurIPS publication validates the approach academically.
