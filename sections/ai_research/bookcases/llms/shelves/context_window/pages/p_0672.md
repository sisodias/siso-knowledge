# Sparse Attention Examples from OpenAI

**Repository**: [openai/sparse_attention](https://github.com/openai/sparse_attention)

**Stars**: 1611 | **Language**: Python | **Updated**: 2026-03-10

**Description**: Examples of using sparse attention from the "Generating Long Sequences with Sparse Transformers" paper. The original reference implementation for sparse attention patterns (strided and fixed).

**Research**: This is the seminal work on sparse attention from OpenAI. Introduced the concept of selecting attention heads with strided patterns or fixed local patterns to reduce quadratic scaling. Many modern sparse attention methods build on these patterns.

**Why it matters**: Foundation work that established the field of sparse attention for long sequences. Referenced by nearly all subsequent sparse attention papers.
