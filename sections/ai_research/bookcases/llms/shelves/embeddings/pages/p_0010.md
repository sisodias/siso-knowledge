# VectorDBBench provides standardized comparison of Qdrant, Milvus, Weaviate, and Pinecone

**Claim**: VectorDBBench (1k stars, from Zilliz/Milvus team) is the only comprehensive benchmarking toolkit for vector databases, measuring QPS, latency, recall, and cost-per-query across providers.

**Why it matters**: Choosing a vector DB requires data, not marketing. VectorDBBench enables apples-to-apples performance comparison for a given vector dimensionality and dataset size.

**Source**: https://github.com/zilliztech/VectorDBBench
