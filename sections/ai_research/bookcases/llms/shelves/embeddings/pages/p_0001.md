# Hugging Face sentence-transformers is the gold standard for text embeddings

**Claim**: Hugging Face sentence-transformers (18.4k stars) is the definitive library for producing state-of-the-art sentence embeddings, supporting 100+ pretrained models with a simple fit()-free API.

**Why it matters**: Most RAG and semantic search pipelines start here. Its model hub integration means new embedding advances (SBERT, MPNet, BGE) land in production code within days of publication.

**Key models it serves**: all-MiniLM-L6-v2 (default for ChromaDB), all-mpnet-base-v2, bge-large-en-v1.5, paraphrase-multilingual-MiniLM-L12-v2.

**Source**: https://github.com/huggingface/sentence-transformers
