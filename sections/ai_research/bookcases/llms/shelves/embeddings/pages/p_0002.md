# HuggingFace text-embeddings-inference enables fast Rust-based embedding serving

**Claim**: HuggingFace text-embeddings-inference (TEI, 4.6k stars) is a Rust-based embedding inference server that delivers 4-10x throughput vs Python servers while supporting ONNX and Flash Attention for BGE, GTE, and E5 models.

**Why it matters**: Production embedding serving demands throughput and latency at scale. TEI is the recommended deployment target for self-hosted embedding models, backing the HuggingFace Inference Endpoints product.

**Source**: https://github.com/huggingface/text-embeddings-inference
