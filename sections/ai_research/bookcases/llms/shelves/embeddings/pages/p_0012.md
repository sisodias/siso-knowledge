# RAG-Retrieval unifies embedding fine-tuning with ColBERT and reranking techniques

**Claim**: RAG-Retrieval (1.1k stars) provides a unified framework for fine-tuning embedding models, ColBERT-style late interaction retrieval, and rerankers in RAG pipelines.

**Why it matters**: The gap between embedding retrieval and reranking is bridged by this toolkit, enabling the 2-stage retrieve-then-rerank pattern that consistently outperforms single-stage retrieval.
