# LlamaIndex finetune-embedding provides synthetic data recipes for embedding fine-tuning

**Claim**: finetune-embedding (525 stars, LlamaIndex) generates synthetic query-document pairs for fine-tuning embedding models on domain-specific corpora without manual labeling.

**Why it matters**: Labeled embedding training data is expensive. Synthetic query generation with LLMs enables rapid domain adaptation for specialized RAG (codebases, internal docs, technical manuals).
