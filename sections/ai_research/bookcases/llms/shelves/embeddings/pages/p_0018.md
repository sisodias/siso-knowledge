# pg_embedding brings HNSW ANN search directly into PostgreSQL at 577 stars

**Claim**: pg_embedding (577 stars, Neon) implements HNSW approximate nearest neighbor search as a PostgreSQL extension, enabling vector similarity search without a separate vector DB for workloads already on Postgres.

**Why it matters**: The pgvector extension predates it, but pg_embedding's HNSW implementation delivers 10-100x better recall/latency tradeoffs, making Postgres a credible single-database option for moderate-scale RAG.

**Source**: https://github.com/neondatabase/pg_embedding
