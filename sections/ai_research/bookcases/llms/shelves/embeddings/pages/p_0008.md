# Weaviate combines vector search with structured filtering at 15.8k stars

**Claim**: Weaviate (15.8k stars, Go) uniquely combines vector search with structured (SQL-style) filtering in a single query, plus built-in text vectorization modules and a GraphQL API.

**Why it matters**: Real-world RAG requires filtered retrieval (e.g., date > 2024, category == news). Weaviate's hybrid approach eliminates the need for post-filtering workarounds common in pure vector DBs.
