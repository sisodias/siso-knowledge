# Code is free — implementation is no longer the scarce resource

**Claim**: Implementation is no longer the scarce resource of software engineering. Every engineer has access to 5, 50, or 5,000 engineers worth of capacity 24/7. The scarce resources are now: human time, human+model attention, and model context window.

**Why it matters**: This inverts the classical stack-rank of engineering work. In the old world, human time forced P3s to die. In the token-abundant world, all P3s get kicked off immediately — maybe 4x in parallel. Maintenance burden as a reason to not write code evaporates because agents are infinitely parallel and patient; refactor/delete is as cheap as add.

**Operational consequence**:
- Localization and i18n ship day one on internal tools
- Migrations *finish* instead of hanging open for six months
- The best parts of software engineering (tests, docs, observability) are available in every product by default

**For SISO Bifrost**: Validates parallel worker spawn per phase. The constraint isn't "how many workers" — it's "can the Planner define zero-overlap file scopes fast enough." Lean into fan-out.
