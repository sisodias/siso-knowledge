# Garbage Collection Day — weekly categorical elimination of slop

**Claim**: One day a week (Fridays, in Lopopolo's team), every engineer stops feature work and focuses exclusively on taking the slop they observed during the week and categorically eliminating it — so it never happens again.

**Why it matters**: This is the ratchet that converts one-off code-review comments into durable repo-level prompts. A reviewer leaves the same feedback twice? That's a failure of the harness. Write a lint, write a test, write a reviewer-agent persona, write a doc — whatever prevents the class of mistake from recurring.

**The loop**:
1. Observe repeated human feedback on PRs over the week
2. Bucket by failure class (not by individual file)
3. Write a durable guardrail (lint / test / doc / reviewer-agent prompt)
4. Auto-inject at the right moment (see p_930)
5. The entire class dies forever

**For SISO Bifrost**: This is exactly what `.claude/feedback/phase_X_fixes.md` *should* compound into, but currently doesn't. Each feedback file dies with its PR. We should run Garbage Collection weekly: roll up all verifier rejections across all projects into durable skill / agent-prompt updates. Propose as recurring job.
