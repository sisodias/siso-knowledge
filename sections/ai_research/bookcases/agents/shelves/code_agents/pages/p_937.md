# Remove-yourself-from-the-loop as the north-star metric

**Claim**: "Every time I have to type `continue` to the agent is a failure of the harness to provide enough context around what it means to continue to completion."

**Why it matters**: This is the single most actionable metric in the talk. Every interrupt is a signal. Every "yes, keep going" click means the harness didn't know what success looks like. The goal isn't to approve more things faster — it's to make approval unnecessary because the agent can self-judge.

**Operational version**:
- Count interrupts per task
- For each interrupt, ask: what text would have let the agent proceed without me?
- Inject that text at the moment the agent would need it (see p_930)
- Interrupt count trends to zero

**Lopopolo's reality**: He kicks off tasks, straps his laptop into the back of his car, commutes 30 minutes, and the task is done on arrival — because the skills tell the agent "you go until tests are green." No clicks required in-transit.

**For SISO Bifrost**: We should instrument interrupt count per phase. Every time the orchestrator (me) has to nudge a worker or re-dispatch, log it. Roll up weekly. The top interrupt classes are the next durable-guardrail targets. This pairs with Garbage Collection Day (p_933).
