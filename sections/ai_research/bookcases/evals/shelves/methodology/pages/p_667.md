# Human preference evaluation biases

**Claim**: Human preference evaluation suffers from inherent biases that must be controlled for when designing eval pipelines.

**Why it matters**: Without accounting for bias, human eval results can mislead product decisions. Understanding these biases helps build more reliable evaluation systems.

**Known biases in human eval**:

1. **Position bias**: Users tend to prefer the first response when comparing two options
   - *Mitigation*: Randomize order, use pairwise A/B with counterbalancing

2. **Acquiescence bias**: Raters tend to agree with statements regardless of content
   - *Mitigation*: Use comparative rather than absolute scales

3. **Recency bias**: More recent interactions disproportionately influence ratings
   - *Mitigation*: Require minimum engagement before rating, use rolling windows

4. **Anchoring effects**: Initial impressions color subsequent judgments
   - *Mitigation*: Separate eval sessions, randomize presentation order

5. **Hedonic adaptation**: Raters habituate to improvements over time
   - *Mitigation*: Track relative improvement, not absolute scores

**Best practice**: Always run human evals with proper controls and statistical significance testing.
