# Dynamic arenas outperform static benchmarks

**Claim**: Dynamic arenas (like Chatbot Arena) outperform static benchmarks for capturing real-world model performance because they use comparative evaluation rather than absolute scoring.

**Why it matters**: Static benchmarks saturate quickly as models memorize answers. Dynamic comparative evaluation stays relevant because it tests relative preference between models on novel tasks.

**Key patterns**:
- **Elo rating systems**: Model comparison through pairwise battles produces more robust rankings than dataset-based scoring
- ** crowdsourced evaluation**: Real users with diverse backgrounds provide more representative signal than small expert panels
- **Continuous challenge sets**: The best arenas refresh their prompts regularly to prevent contamination

**When to use each**:
- Static benchmarks: Quick sanity checks, regression testing on known capabilities
- Dynamic arenas: Comparing top models, evaluating open-ended generation, measuring user satisfaction
