# Book: Harness Engineering — Ryan Lopopolo (OpenAI)

**Pages**: 10 | **Shelf**: ai_research/agents/code_agents | **Updated**: 2026-04-19

**Source**: AI Engineer talk #343 — Ryan Lopopolo, MTS at OpenAI. "How to Build Software When Humans Steer, Agents Execute."

**Core thesis**: Implementation is no longer scarce. Code is free. The scarce resources are human time, human+model attention, and model context window. Every engineer is now a staff engineer commanding 5–5000 agents 24/7. Your job: make the codebase legible to agents and inject the right context at the right time.
