Owning domain · corpus + production pipelines + independent Research Works

SISO Knowledge

The system that acquires, curates, stores, indexes, relates, and retrieves durable knowledge. It is not the public Great Library website, the reusable agent stack, or a dumping ground for products and runtime data.

One-line filing rule

If the durable outcome is reusable knowledge, it belongs here. If the durable outcome is an app, an agent capability, a UI system, or machine state, it does not.

The production flow

Acquire

pipelines/ and Knowledge-specific operators collect explicit sources with rights and provenance.

Curate

Normalization, scoring, routing, and synthesis turn sources into reviewable knowledge records.

Store

sections/ holds atomic pages; books/ holds reviewed synthesis; module_templates/ defines their contracts.

Project

_index/ and graph/ are deterministic, rebuildable discovery surfaces—not alternate writers.

Research Works

Foundry and Evidence Engines remain independently forkable Git repositories under research/.

Publish

The Great Library indexes evidenced Works and Releases. It does not absorb private corpora or become this repository's parent.

Canonical hierarchy

Section → Bookcase → Shelf → Page (one atomic insight) / Book (reviewed synthesis or manifest)
