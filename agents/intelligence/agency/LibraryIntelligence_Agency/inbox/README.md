# Agency Intelligence — Research Review Inbox

Heartbeat drops Agency-relevant integration opportunities here for review.

## What belongs here

Research on topics relevant to SISO Agency:
- Landing pages and marketing sites
- E-commerce implementations
- Client-facing deliverables
- Website/_store builds
- Product pages and shop integrations
- Client workflow automation

## Format

```json
{
  "type": "integration_review",
  "source": "os_insights",
  "timestamp": "2026-03-20T22:44:36",
  "tier": "high",
  "title": "Landing Page Pattern",
  "source_detail": "YouTube",
  "components": "landing",
  "insight": "The insight...",
  "url": "https://...",
  "status": "pending_review",
  "routed_to": "agency"
}
```

## Review Workflow

1. Read JSON files in this inbox
2. Relevant to Agency work → create feature spec in `workspace/`, then delete file
3. Not relevant → delete file

## Tiers

- **critical**: Client-ready patterns
- **high**: Agency workflow improvements
- **medium**: Inspiration and reference
