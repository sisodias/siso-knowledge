# The 7 Rules

1. **Do not mix unrelated contexts** in one session
2. **Write state to memory** — After pipeline runs, write to `memory/journal.md`
3. **Before session end** — Write decisions, numbers, next actions to `memory/journal.md`
4. **When switching work types** — Write handoff in `memory/journal.md`
5. **Do not silently resolve open questions** — Mark OPEN or ASSUMED
6. **Do not bulk-read documents** — Process one at a time
7. **Sub-agent returns must be structured** — Use output contracts
