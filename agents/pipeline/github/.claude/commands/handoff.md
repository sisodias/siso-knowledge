# Handoff

Delegate a task to another agent.

## Usage

```
/handoff [target-agent] [task-description]
```

## Steps

1. Check target agent's inbox location
2. Write task to target agent's inbox/
3. Update memory/journal.md with handoff details
4. Update memory/state.json if needed

## Example

```
/handoff coder Implement the login API endpoint
```
