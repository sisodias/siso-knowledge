# Agents

Subagent definitions. Claude can delegate to these natively.

## Format

```markdown
# Subagent Name

## Role
What this subagent does.

## Capabilities
- capability 1
- capability 2

## Usage
When to invoke this subagent.
```

## Available Subagents

| Agent | Role |
|-------|------|
| researcher | Research tasks |
| coder | Code implementation |
| reviewer | Code review |
